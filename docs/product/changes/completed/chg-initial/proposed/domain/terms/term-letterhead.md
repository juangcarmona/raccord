## Definition

The page background combined with a template at generation, carrying the company's logo, details and visual identity. Attributes:
- name;
- a PDF file of one or more pages;
- page size: a standard size (A4, Letter) or a custom width and height;
- margins (top, bottom, left, right) that keep generated content clear of the printed header and footer;
- the document types for which it may be chosen;
- whether page numbers are printed.
Page n of a document uses page n of the letterhead; pages beyond the letterhead's last page reuse its last page. For equipment labels, the page size equals the label size.

## Distinguish From

Document template: decides the generated content; the letterhead decides the background and the printable area.

## Usage

Default per project type and per document type, overridable for each generated document.
