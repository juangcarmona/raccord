## Definition

A personnel document kept on a crew member: name (required), document type, start date, end date, signature status and one or more files (for example front and back of an identity card) that together form one document. Documents are either uploaded or generated from crew data as an agreement, optionally sent for digital signature. Existing files of a crew member can be converted into crew documents.

## Distinguish From

Attached file: an unclassified file on a record. Personal crew schedule document: an output sent to the crew member about planning.

## Usage

Checking contract end dates, licences and certificates before planning; renewing contracts remotely.
