## Rule

An e-mail template or personal text template is offered only when composing for a document of the type it was saved for.

## Rationale

Wording differs between quotations, invoices and packing slips.

## Examples

See SB-DOC-TEXT-TEMPLATE-WRONG-TYPE-NOT-LISTED.

## Exceptions

None.
