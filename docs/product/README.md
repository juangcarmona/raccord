# Product Intent

Product Intent is maintained exclusively as Product Definition as Code.

- Accepted intent: [`model/`](model/)
- Product Change decisions: [`changes/`](changes/)

Completed changes retain their `change.md` decision record. Their proposed artifact copies are removed after application because the accepted artifacts live in [`model/`](model/) and prior versions remain in Git history. When applying a change, check for links to its proposed copies and update them before removing those copies.

Do not add narrative product-definition, roadmap or capability documents here. Product semantics change through ProductShape Product Changes and are applied explicitly.
