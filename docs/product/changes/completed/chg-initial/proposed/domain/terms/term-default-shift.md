## Definition

A reusable shift template: name, duration, total break time, optional default start and end time, availability-blocking flag, quantity, remarks and tags. Its values are copied into each shift created from it.

## Distinguish From

Shift: a concrete dated occurrence.

## Usage

Fast creation of recurring kinds of internal work.
