## Rule

A signing element in a document lets recipients sign only when the company setting allowing customers to sign digitally is on.

## Rationale

Signature collection is a deliberate company decision.

## Examples

- A quotation generated while signing is disabled offers no usable signing.

## Exceptions

None.
