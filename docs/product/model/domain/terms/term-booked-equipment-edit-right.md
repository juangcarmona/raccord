## Definition

A project permission deciding whether planned equipment can be changed once it has been booked in the warehouse: always allowed; never for booked lines; or no changes at all to a project that has booked equipment.

## Distinguish From

Not the warehouse right to add extra or other items, which overrides it during packing.

## Usage

Protects packing lists that the warehouse already worked on.
