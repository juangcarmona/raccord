## Rule

Searching within a project's planned equipment highlights every matching line, marks the current match distinctly, and lets the user step to the previous or next match.

## Rationale

Large projects need fast location of lines.

## Examples

See SB-TRB-STEP-THROUGH-MATCHES.

## Exceptions

None.
