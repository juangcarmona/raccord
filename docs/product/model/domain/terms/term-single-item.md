## Definition

An equipment item of the simplest type: one physical piece without content. It can carry accessories and alternatives, and can be default content of kits.

## Distinguish From

- Physical kit: physically also an item, but with content that is consumed from stock.

## Usage

Default type for new equipment; the building block of every kit's content.
