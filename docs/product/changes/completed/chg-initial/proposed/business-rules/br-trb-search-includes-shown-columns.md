## Rule

Searching the resource list while planning equipment or crew matches the name and the additional fields that the user has added as columns to that list; fields not shown as columns are not searched.

## Rationale

Users control which attributes are searchable without a separate search configuration.

## Examples

See SB-TRB-SEARCH-BY-ADDED-COLUMN.

## Exceptions

None.
