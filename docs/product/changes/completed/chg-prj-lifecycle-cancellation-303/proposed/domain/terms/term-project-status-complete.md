## Definition

The final normal status of a project: the team declares that the project, including its follow-up work after execution, is closed. Only a user sets it, normally after Execution done; it is never set automatically. It keeps the project in the Confirmed group, so the project still counts in revenue figures and stays visible in history. Complete blocks operational edits and new planning; invoicing, audit access and permitted corrections remain available. Reopening is explicit.

## Distinguish From

Execution done, which is reached automatically.

## Usage

Confirmed group; final normal state.
