## Definition

What an invitation asks and what a yes does: availability (yes marks the person available, no unavailable; no job details shown), final planning (yes plans the person visibly on the function), draft planning (yes plans the person invisibly), reservation (yes reserves the person for the function times or the specified period; no job details shown). Period invitations use only availability or reservation.

## Distinguish From

Plan status: the result of a planning-type acceptance.

## Usage

Chosen per send; each type has its own default message text.
