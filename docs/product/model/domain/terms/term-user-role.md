## Definition

A named set of permissions assigned to user accounts; every user has exactly one role, and the role decides which modules they see and what they may do in each, identically in the web product, in the mobile web app and in calendar feeds. Attributes: name and one value per role permission. Roles can also be selected for single sign-on enforcement.

## Distinguish From

Not a crew function (the job someone is planned for). Not the account manager of a project, which is a per-project responsibility.

## Usage

The four predefined roles can be edited and others added in configuration; assigned on each crew member's login information; used to filter crew members.
