## Definition

A named section (for example food, hotels, transport) that groups additional costs of a project, shows a subtotal and determines how they are presented on documents. If none exists, a default group is created with the first cost.

## Distinguish From

Revenue category; equipment group.

## Usage

Every additional cost belongs to a group.
