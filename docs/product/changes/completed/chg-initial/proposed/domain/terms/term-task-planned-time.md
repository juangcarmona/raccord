## Definition

The number of hours a task is expected to take. It is an estimate of effort, not a scheduled slot, and is compared with tracked time. Linked to a service, it feeds the service's planned cost.

## Distinguish From

Tracked time: the actual hours. Function times: when work happens.

## Usage

Estimation and margin control.
