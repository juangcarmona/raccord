## Constraint

A letterhead must be uploaded as a PDF file whose page dimensions match the page size declared for it.

## Rationale

The letterhead is overlaid page by page as a fixed background; PDF preserves exact layout.

## Consequences

Companies design stationery in external tools and export it to PDF; other image formats cannot be used as letterheads.
