## Definition

A free label without spaces attached to records (projects, invoices, equipment, contacts, crew members, vehicles, tasks, statistics) to group them across folders. Records are filtered by tags matching any or all selected tags. Every import automatically tags the created records with an import-date-time tag. Creating and deleting tags requires permission and is limited to modules the user can access.

## Distinguish From

Record folder: a single storage place per record. Custom field: typed data.

## Usage

Grouping customers and suppliers, regions, skills, phases; undoing imports.
