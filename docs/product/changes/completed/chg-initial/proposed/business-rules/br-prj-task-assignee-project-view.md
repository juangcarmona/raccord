## Rule

A task assignee gets the project overview and files that a scheduled crew member gets, never its financial figures; their role decides the precise scope.

## Rationale

Assignees need context.

## Examples

A freelance designer assigned a task sees venue and drawings but no prices.

## Exceptions

None.
