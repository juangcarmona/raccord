## Definition

A request created by a staff member asking for a project to be set up, from which a project can be created. Attributes: requester (the staff member), requested client and location, requested equipment lines with quantities, requested times, and its request status. Processing it means choosing the client and location from the contact database and the equipment from the catalogue, then creating the project.

Lifecycle (see project request status): Received, then either Declined or Converted (a project is created).

## Distinguish From

Project in Inquiry status: already a project.

## Usage

Internal demand for new projects; notified to account managers.
