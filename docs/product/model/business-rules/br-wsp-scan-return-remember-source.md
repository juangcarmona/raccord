## Rule

For bulk articles the technician may make the chosen project the remembered source, so subsequent bulk scans are booked against it first.

## Rationale

Speeds up returning large quantities from one job.

## Examples

- After remembering project 2, every scanned cable is booked back to project 2.

## Exceptions

None.
