## Definition

One calendar or task list exposed through a private feed: all functions the user may see, the user's own functions, the user's own appointments, public appointments, all projects, reservations, the user's tasks and public tasks. Each stream has its own private address.

## Distinguish From

Not a project calendar view inside the product.

## Usage

Chosen by the user; task streams appear in the calendar application's task list where it supports them.
