## Responsibility

The installation's configuration and access: users, the four predefined roles and permissions, sign-in (local accounts and optional single sign-on), company settings, number series, custom fields, tags, folders, saved views, notifications, calendar feeds, the public API with tokens, and backups.

## Language

Users, roles, permissions, settings, series, custom fields, notifications, calendar feeds, API tokens.

## Boundaries

Server operation is the installation administrator's concern.

## External Relationships

Configures every other context.
