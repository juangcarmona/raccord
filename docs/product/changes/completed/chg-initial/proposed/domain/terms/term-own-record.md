## Definition

The ownership scope used by permissions that distinguish own from all records:
- Own project: a project for which the user is the account manager.
- Own invoice: an invoice of a project the user is account manager of, or, without project, an invoice the user created.
- Own appointments, availability, tasks, hours and templates: those created by or belonging to the user.

## Distinguish From

Not records the user is merely planned on, which is a separate visibility scope for schedules and warehouse projects.

## Usage

Lets roles grant broad access to one's own work while restricting colleagues' records.
