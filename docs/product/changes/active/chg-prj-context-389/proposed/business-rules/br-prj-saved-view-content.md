## Rule

A saved project view stores date range, tags, project status selection, filters and columns under a name with a visibility; earlier presets and column sets are available as views and can be combined into a new view.

## Rationale

Selecting a saved view restores the whole working set at once.

## Examples

A 'My pending' view combines status Pending and account manager = me.

## Exceptions

None.
