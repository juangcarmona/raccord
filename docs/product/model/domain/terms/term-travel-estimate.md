## Definition

The distance and travel time from the company's location to a contact's visiting address. It is calculated on explicit refresh and stored on the contact; only a refreshed value is used when the contact is chosen on a project.

## Distinguish From

Crew travel time rules: crew planning concern.

## Usage

Project location map and logistics.
