## Definition

The document of an invoice draft, marked as a preview so it cannot be mistaken for a final invoice.

## Distinguish From

Invoice document (TERM-INVOICE-DOCUMENT), which is produced only for issued invoices.

## Usage

Used to check layout and content before finalizing.
