## Definition

A calendar of one person's commitments: appointments, functions they are scheduled on, availability (available, unavailable, unknown) and, when selected, project days (equipment out, equipment in, need crew, need transport). With sufficient rights it shows colleagues' items too. A project can be started from a day in it.

## Distinguish From

Project overview: all projects. Crew planner: staffing tool.

## Usage

Daily orientation for crew and coordinators; calendar synchronisation.
