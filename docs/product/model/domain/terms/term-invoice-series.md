## Definition

A numbering family identified by a short code of uppercase letters and digits, for example F for ordinary invoices and R reserved for rectifying invoices.

## Distinguish From

Invoice number: one value allocated within a series.

## Usage

Each draft names the series that will number it; one series is the default.
