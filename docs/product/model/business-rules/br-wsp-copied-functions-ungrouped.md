## Rule

Copying a function to several days (by recurring pattern or selected dates) creates one function per day, but the copies are not placed in the function groups of the original; they must be moved manually. Multi-day work is planned as one function per day, not one long function, so hours, breaks and reporting are correct per day.

## Rationale

Daily time registration requires daily functions.

## Examples

- A week of stage-hand work becomes seven functions of eight hours.

## Exceptions

None.
