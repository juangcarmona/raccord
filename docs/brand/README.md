# Raccord visual direction

Status: exploratory v1  
Last updated: 2026-10-06

## Brand idea

Raccord is the continuity layer that keeps an audiovisual production coherent from planning to delivery. The visual language should feel operational, precise, calm, and distinctly audiovisual without relying on cameras, film reels, clapperboards, or generic play buttons.

## Logo direction

The first exploratory mark is [`raccord-mark-v1.png`](../../assets/brand/raccord-mark-v1.png). It uses two linked frame-like paths to suggest continuity, connection, and a production workflow becoming one coherent whole.

This is a concept asset, not yet a final trademark-ready logo. The next design pass should produce a deterministic SVG version, monochrome variants, favicon sizes, and a wordmark lockup.

## Initial palette

| Token | Hex | Use |
|---|---|---|
| Ink | `#0B1020` | Primary text, navigation, dark surfaces |
| Electric cyan | `#2DE2E6` | Primary action, links, active states |
| Signal coral | `#FF6B5E` | Warnings, highlights, small accents |
| Cloud | `#F5F7FA` | Light backgrounds |
| Slate | `#667085` | Secondary text and metadata |
| White | `#FFFFFF` | Cards and high-contrast text |

## Design principles

- Dense enough for operations, calm enough for long workdays.
- Clear status colors and strong information hierarchy.
- Rounded geometry used sparingly; avoid playful consumer-app styling.
- Accessible contrast in every state.
- The mark must work at 16px, in monochrome, and on light or dark backgrounds.
- Product UI should feel like a control surface, not a marketing site.

## Typography direction

Use a highly legible grotesk or humanist sans-serif for the product UI. Candidate families can be evaluated later; no font decision is final until licensing, rendering, and accessibility are checked.
