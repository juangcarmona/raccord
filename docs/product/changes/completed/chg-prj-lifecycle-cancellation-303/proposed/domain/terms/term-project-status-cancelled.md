## Definition

The project will not go ahead. Reachable only manually. Its equipment reservations are released immediately; it is hidden from operational overviews but kept in statistics and can be reused later.

## Distinguish From

Deleted project: removed permanently.

## Usage

Cancelled group; triggers the cancellation workflow.
