## Definition

A numbered revision of a quote or contract. Creating a new version raises the version number and keeps the previous version as a file of the project; overwriting replaces the content of the current version without changing number or version.

## Distinguish From

A new quote (new document number), which is a separate offer.

## Usage

Shows the customer the latest offer while keeping earlier ones for reference.
