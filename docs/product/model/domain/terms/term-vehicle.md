## Definition

A transport resource that can be planned on transport functions and shifts: registration number, number of seats, record folder, tags (for example truck, van, car) and a flag deciding whether it is shown and plannable in planning.

## Distinguish From

Equipment: rented-out goods. Transport function: the need for transport on a project, which vehicles fill.

## Usage

Transport planning, reservations of vehicles, call sheets.
