## Why

The first native Contacts implementation received current source without the reviewed historical runtime code. Its NuGet restore also exhausted the private 2 GiB scratch volume, and GitHub rejected PR creation under the repository Actions setting.

## What Changes

Provide the approved recovery as an immutable, issue-specific implementation seed with explicit base/head commits. Place NuGet packages and HTTP cache in the ignored per-attempt workspace obj tree for every .NET check. Preserve all required checks and the serial dependency holds. Record the repository setting correction and native publication effects separately from implementation acceptance. Use the provider-owned disposable PostgreSQL service for isolated workloads, retain the actual Aspire/Playwright journeys with installation-local file storage, and prevent wrapper-owned log path collisions.

## Capabilities

### New Capabilities

- `contacts-native-recovery`: source-bound input and reproducible independent checks for the approved Contacts recovery.

## Impact

Adopter implementation policy, test fixtures, the Testing-only AppHost service configuration, and operational delivery records. The seed implements accepted FR-CON-002; this policy changes no product semantics, credentials, production configuration or shared history.
