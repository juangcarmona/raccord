## Definition

The time zone a single user currently uses to display and enter times, chosen by searching a city; only that user's view changes and the page refreshes when it is switched. Times typed into a schedule are interpreted in this time zone, not in the project's.

## Distinguish From

Not the project time zone and not the workspace default.

## Usage

Available when multiple time zones are enabled.
