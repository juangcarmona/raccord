## Definition

An equipment slip generated for selected articles, sized to a physical label by a letterhead whose page size equals the label. The label shows article-level information and the scan code. A generated label can be downloaded as PDF and saved to the article.

## Distinguish From

Combination label (TERM-COMBINATION-LABEL): for a kit or case. Scan code: the identifier the label usually displays.

## Usage

Set up by administrators; printed by warehouse staff on single-label printers.
