## Definition

Derived state of a function or shift comparing its planned resources with the required quantity and their visibility: fully planned (quantity reached, all visible), fully planned but not yet visible (quantity reached, at least one assignment in draft), not fully planned (fewer resources than required).

## Distinguish From

Plan status: per assignment. Invitation status: offers not yet answered.

## Usage

Signals in planning overviews which functions still need people.
