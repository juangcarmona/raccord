## Definition

The task board that every project has automatically, showing all tasks linked to that project. Visible to Admin and Office users who can edit all projects and to the people it has been shared with (colleagues or invited external users). Sharing it is an Admin or Office action.

## Distinguish From

Team task board: one team across all projects. Access to the project itself: not implied by board access.

## Usage

Project progress conversations, collaboration with externals.
