## Definition

Who may read a note: everyone with access to the record, or account managers only. The default for a new note is account managers only; a project template can carry notes already set to everyone.

## Distinguish From

Display target: where a note appears, not who may read it.

## Usage

Confidential remarks versus crew instructions.
