## Definition

Classification of a function as crew (filled by people, priced by time) or transport (filled by vehicles, priced by distance travelled). Apart from pricing, both kinds behave alike.

## Distinguish From

Default versus one-off: about reuse, not about kind.

## Usage

Determines which resources can be planned and which price basis applies.
