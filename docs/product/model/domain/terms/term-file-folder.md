## Definition

A named, nestable container for attached files on a single record. Attributes: name, parent folder, confidential flag. A confidential folder makes everything inside it confidential and is visible only to users allowed to download all files; a non-confidential folder may contain both.

## Distinguish From

Record folder: organises records (contacts, equipment) in a module, not files.

## Usage

Structuring large project file sets.
