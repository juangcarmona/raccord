## Definition

The announced retirement of a field, value or format, with the place it moves to and a transition period during which old and new places return the same values. Breaking removals without transition are flagged as breaking changes in the version notes.

## Distinguish From

Not a type correction of the specification, which changes documentation without changing data.

## Usage

Announced in version notes with the action integrators must take.
