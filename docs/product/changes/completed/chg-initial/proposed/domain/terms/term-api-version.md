## Definition

A numbered release of the public interface with dated notes listing new resources and operations, new and renamed fields, type corrections, breaking changes and fixes. The machine-readable specification is published with it.

## Distinguish From

Not the product release number of the user interface.

## Usage

Integrators follow it to keep their integrations working.
