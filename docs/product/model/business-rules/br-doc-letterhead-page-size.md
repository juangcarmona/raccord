## Rule

The page size of a generated document is the letterhead's page size: a standard size (A4 or Letter) or a custom width and height, which should match the dimensions of the letterhead file.

## Rationale

One mechanism serves full-page documents and small labels alike.

## Examples

- Labels of 3 x 3 cm are produced by a letterhead of width 3 and height 3.
- A letterhead file of Letter size declared as A4 is placed incorrectly; correcting the dimensions fixes the placement.

## Exceptions

None.
