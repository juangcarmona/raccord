## Definition

A saved, filtered view over tasks the viewer can access, shown as cards in columns (board view) or as rows (list view). Columns or sections come from the chosen grouping (status by default; also assignee, tags, linked item), with optional subgroups; filters cover project status and type, colour, expired deadlines and more. A board is not a container: a task can appear on several boards and still has one status. Kinds: project task board and team task board.

## Distinguish From

Task list in the tasks area: all accessible tasks without board semantics.

## Usage

Daily coordination of production work.
