## Rule

After an item is added to a project, the name of its planned line can be changed freely; searching within the project matches the line's current name, not the catalog name.

## Rationale

Lines can be described in the customer's words.

## Examples

See SB-TRB-RENAMED-LINE-SEARCH.

## Exceptions

None.
