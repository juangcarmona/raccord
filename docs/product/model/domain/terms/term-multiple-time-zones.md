## Definition

A workspace setting that, when enabled, lets each project have its own time zone and lets each user switch their own viewing time zone without affecting others. Daylight-saving changes are converted automatically.

## Distinguish From

Not the default time zone itself, which remains the baseline.

## Usage

For companies operating across regions.
