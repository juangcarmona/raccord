## Definition

Company-level configuration of the text of invitation emails, sent through the company mail account: signature, subject, salutations and greetings, one default message per invitation type (resettable to the product defaults), and the default set of information shown (due date, location, client name, function group, project leader, account manager), which can be changed per send.

## Distinguish From

Document template: built-in template with branding for printed schedules and call sheets.

## Usage

Wording and disclosure control of invitations.
