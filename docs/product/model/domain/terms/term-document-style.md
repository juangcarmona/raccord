## Definition

The branding of the company's documents: logo, colours and standard texts used by the built-in document templates, together with the letterhead chosen for each document type.

## Distinguish From

Letterhead: the page background, not the branding of the generated content.

## Usage

Set once by an administrator and applied to all document types.
