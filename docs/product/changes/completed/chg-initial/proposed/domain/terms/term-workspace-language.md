## Definition

The language chosen for the whole workspace, used for the interface default, notifications, default settings and the templates provided. Chosen at set-up and changeable later.

## Distinguish From

Not the profile language, which only changes what one person sees in the browser; not a document template's language.

## Usage

Affects messages sent by the product and initial content.
