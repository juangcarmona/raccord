## Definition

A named, reusable copy of a project used to start new projects. It captures the client and location (if any), the time schedule, notes and tasks (with planned time, subtasks and relative deadlines), equipment groups with planned equipment, crew and transport functions, additional costs, and financial details (discounts, VAT, refundable deposit), and the status the copy starts in. It does not capture which crew members or vehicles are assigned to functions. Templates cannot be edited in place; they are replaced.

## Distinguish From

Project type: carries settings and defaults, not content. Duplicating a project: one-off copy without a stored template.

## Usage

Fast creation of recurring kinds of jobs (dry hire with pickup and return, two-day event with build and break days).
