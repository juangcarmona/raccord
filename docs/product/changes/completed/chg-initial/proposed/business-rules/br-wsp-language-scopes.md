## Rule

Changing the workspace language changes the interface default, notifications, default settings and provided templates; changing a profile language only changes the screens that person sees.

## Rationale

Company communication must stay consistent regardless of each user's preference.

## Examples

- A planner using English screens in a workspace set to Dutch still sends Dutch notifications.

## Exceptions

- Existing document templates keep their language.
