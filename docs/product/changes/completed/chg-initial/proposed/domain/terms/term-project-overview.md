## Definition

The browsable presentation of all projects. Modes: list (configurable columns, optional timeline of planning and usage periods for selected projects), per day (projects organised by day, with crew and vehicles columns), calendar (30 days, creating a project from a day) and timeline (horizontally scrollable). Supports filters, tags, status filters, presets, saved views, columns and a details panel (name, location, client and contact person, calculated planning and usage period, linked, notes, tasks, tags, files).

## Distinguish From

Personal schedule: a person's own calendar. Task board: tasks only.

## Usage

Daily operations and planning meetings.
