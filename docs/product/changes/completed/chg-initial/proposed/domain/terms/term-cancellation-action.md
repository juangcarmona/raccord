## Definition

A follow-up action offered when a project is cancelled, only when it applies: withdraw crew invitations (sent ones expire, unsent ones are deleted), complete all open tasks, remove planned crew members and vehicles from functions (functions remain), inform crew members by e-mail with the updated schedule and an optional message.

## Distinguish From

Cancelled status itself: set regardless of the chosen actions.

## Usage

Cancellation workflow.
