## Intended Outcome

Financial documents can be produced correctly from the first project.

## Entry Conditions

The installation is set up for the company.

## Journey Narrative

The administrator sets validity and conditions, builds factor lists, reviews ledgers, checks VAT classes and schemes, creates invoice moments and payment terms.

## Variants and Branches

E-invoicing set up as well; location-based tax instead of VAT.

## Completion Conditions

Defaults exist for every financial setting used by quotes and invoices.
