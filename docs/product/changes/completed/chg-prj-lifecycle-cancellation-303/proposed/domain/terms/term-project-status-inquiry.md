## Definition

The customer's wishes have been captured (for example a requested equipment list or 'same as last year') but no planning has been worked out yet. Entered automatically when a project is created from a project request.

## Distinguish From

Draft: planning has started on the company's own initiative.

## Usage

Unconfirmed group.
