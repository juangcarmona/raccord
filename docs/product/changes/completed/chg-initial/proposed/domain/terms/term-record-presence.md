## Definition

The indication, shared live with all users who have the same project open, of which colleagues are currently working in that project. It exists only while those users' live update connections are open.

## Distinguish From

Last seen (login information): the last sign-in of a user; presence is momentary and per project.

## Usage

Helps users avoid overwriting each other's changes on the same project.
