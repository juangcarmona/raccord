## Rule

Newly created equipment, functions and contacts receive the default VAT class or scheme from the financial settings; each item's class can then be changed individually or in bulk.

## Rationale

Avoids untaxed items by omission.

## Examples

A new speaker gets the high rate class.

## Exceptions

None.
