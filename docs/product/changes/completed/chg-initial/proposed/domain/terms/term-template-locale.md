## Definition

The pair of settings on a template that decide the language of its fixed texts and the regional formatting of generated content. The country decides date notation (for example day-month-year with slashes versus dots) and number separators; amounts are in euros.

## Distinguish From

The template country only changes how dates and amounts are formatted; it never changes stored amounts.

## Usage

Set per document type; changed when the company serves customers abroad.
