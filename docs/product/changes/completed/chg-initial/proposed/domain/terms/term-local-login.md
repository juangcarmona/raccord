## Definition

Signing in with the verified email address and a password kept by the installation, as opposed to signing in through an external identity provider.

## Distinguish From

Not external sign-in, which delegates authentication to a Microsoft or Google account.

## Usage

The default way to sign in; always available unless single sign-on is enforced for the user's role.
