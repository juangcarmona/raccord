## Definition

How a changed project is reflected in an existing quote or contract: overwrite (same number and version), new version (version number raised, previous kept), new version without publishing (raised but visible online only after synchronising), or new quote (separate number, required for a new signature). Without regeneration the document keeps its earlier content.

## Distinguish From

Duplicate of an invoice, which copies settings but recomputes content.

## Usage

Chosen whenever a quote or contract is regenerated.
