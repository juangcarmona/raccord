## Definition

A reusable function definition, kept in folders, holding default values for all function attributes. Adding it to a project copies its values into a project function; later edits of the default do not change existing project functions until they are explicitly updated to the default.

## Distinguish From

One-off function: defined inside one project only.

## Usage

Speeds up quoting and planning; standard pricing.
