## Definition

A kind of record offered by the public interface, with its collection, its items and its allowed operations. Coverage grows by version and differs per kind: for example contacts, contact persons, projects, project equipment and functions, crew, crew rates, crew availability, time registrations, equipment, accessories, kit contents, alternatives, vehicles, files and file folders, folders, tasks and task statuses, invoices and payments (read), factor groups, custom-field definitions (read), project and warehouse statuses (read). Some kinds are read-only and some operations, such as creating quotations or invoices, are not offered.

## Distinguish From

Not the user interface's screens, which cover more.

## Usage

Determines what integrations can do.
