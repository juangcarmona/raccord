## Intended Outcome
A crew member sees their work commitments in the calendar application they use daily.
## Entry Conditions
The user can sign in.
## Journey Narrative
The user copies the private address of the streams they want from their personal schedule and subscribes their calendar application to them. From then on planning changes appear there, read-only, on the application's own refresh schedule.
## Variants and Branches
Several streams can be subscribed separately; project streams follow the user's permissions.
## Completion Conditions
The calendar application shows the same schedule as the product within the window.
