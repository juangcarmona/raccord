## Definition

Changing chosen fields to the same value on several selected records of one module at once (for example a discount on many customers, a price on many items, or contract hours on many crew members). Only fields applicable to all selected records' kinds can be changed.

## Distinguish From

Not an import-based update, which can set different values per record.

## Usage

Lists of equipment, contacts, crew members and other modules.
