# Project schedules

## ADDED Requirements

### Requirement: Schedules can shift as one unit

The system MUST shift both schedule boundaries by the requested number of days.

#### Scenario: Shift scheduled work

- **WHEN** an operator shifts a schedule
- **THEN** its start and end dates move by the same number of days
