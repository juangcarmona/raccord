## Definition

A coarse classification of project statuses used for presentation and filtering: Unconfirmed (inquiry, draft, pending), Confirmed (confirmed, in progress, execution done, complete) and Cancelled. Each group has a distinct presentation in overviews and calendars (for example unconfirmed de-emphasised, cancelled struck through), independent of the project colour. Warehouse statuses of packing lists are not project statuses and belong to no group.

## Distinguish From

Project status: the precise state. Project colour: comes from the project or its type.

## Usage

Overview styling, status filters, revenue widgets (confirmed, pending, cancelled).
