## Definition

A place where a note is surfaced: the record's details panel, warehouse handling, the personal schedule of planned crew, quotations and contracts, invoices, and other documents (packing slips, call sheets). A note can have any combination of targets.

## Distinguish From

Note visibility: access restriction.

## Usage

Configured per note, or preset in project templates.
