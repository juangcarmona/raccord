## Definition

A tag placed on crew members (and vehicles) to express a capability, such as truck driver, DJ or forklift operator, and on functions and shifts to express what is required. A crew member matches a function when they carry the same tag text exactly.

## Distinguish From

Generic tag: any label; a skill tag is the same mechanism used for matching people to roles. Certificate document: evidence of a qualification, not a filter label.

## Usage

Filtering crew, the matching-tags crew list.
