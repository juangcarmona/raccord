## Definition

A saved, named text used to start either the e-mail message sent with a document (e-mail template) or the personal text of a document (personal text template). Each text template belongs to one document type and is offered only for that type. Its author chooses who may see and use it. Text templates may contain images; the e-mail for an online quote carries the quote's link and password.

## Distinguish From

Document template: defines the whole document; a text template only pre-fills one free-text field.

## Usage

Saved from the e-mail or personal-text editor and applied from a list while composing.
