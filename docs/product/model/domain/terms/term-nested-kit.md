## Definition

A kit that is content of another kit, forming layers (for example a microphone box inside a touring case). Nesting can be defined in the catalog as default content (permanent) or on one project inside a planned kit (that project only). At most 10 nesting levels are allowed.

## Distinguish From

- Accessory: a separate line, never nested.

## Usage

Used for modular setups.
