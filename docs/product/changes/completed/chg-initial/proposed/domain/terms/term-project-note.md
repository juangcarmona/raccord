## Definition

A titled text message attached to a record (project, contact, equipment, task and others). Attributes: title, text, visibility (everyone or account managers only) and display targets (details panel, warehouse handling, personal schedule of planned crew, quotations and contracts, invoices, other documents such as packing slips and call sheets). Notes can be added from templates, by the automatic project note of a contact, or by e-mail.

## Distinguish From

Contact warning: an alert shown when the contact is selected, not stored on the project. Task: work to be done.

## Usage

Instructions for crew and warehouse, customer feedback, CRM memory.
