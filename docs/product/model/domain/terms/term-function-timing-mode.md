## Definition

How a function's times are determined: linked (to time-schedule periods, following their changes), own times (fixed start and end on the function), duration only (a length without exact times), or unscheduled (added without a date, waiting to be placed on a timeline).

## Distinguish From

Plan status: visibility, not timing.

## Usage

Decides where functions appear: only functions with connected times appear in project-level scheduling lists; unscheduled ones wait in a separate list of the planner.
