## Definition

A node of a user-defined hierarchical folder structure in which records of one module are stored: contacts, equipment, crew members, vehicles each have their own separate structure. Each foldered record lives in one folder. Contacts may instead remain unfiled under BR-CON-FOLDER-HIERARCHY; other module rules are unchanged. Folders can be added as root folders or subfolders, renamed, reordered and moved; a folder that still contains records cannot be deleted. Imports with folder placement place records by path and create missing folders under a chosen root; UC-CON-IMPORT-CONTACTS excludes that placement.

## Distinguish From

Tag: grouping across folders; folders are for storage, not grouping. File folder: inside one record.

## Usage

Organising the contact database (for example freelancers/audio technicians).
