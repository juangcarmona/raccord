## Definition

A project state in which the prices in the financial overview are frozen: later changes to planned equipment, crew and transport no longer change revenue, discounts or totals until the lock is released.

## Distinguish From

Issued invoice immutability, which concerns a document; the lock concerns the live project prices.

## Usage

Typically set after a quote or invoice has been generated so the agreed price stays stable.
