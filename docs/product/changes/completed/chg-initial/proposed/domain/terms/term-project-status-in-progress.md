## Definition

Execution of a confirmed project has started. Set automatically when the first equipment of the project is booked in the warehouse, or by a user.

## Distinguish From

Warehouse statuses such as prepped or on location, which belong to packing lists.

## Usage

Confirmed group; shown on projects being executed.
