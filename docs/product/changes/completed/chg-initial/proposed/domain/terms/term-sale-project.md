## Definition

A project category for selling equipment. Because sold equipment leaves permanently, no planning or usage period is mandatory; everything else behaves like a regular project. Stock of sale items changes when items are booked out (and back in if returned), not when they are planned; booking only updates stock automatically when the project has at least one time period, otherwise stock must be adjusted by hand.

## Distinguish From

Regular project with sale items: also possible and more common.

## Usage

Optional way to handle sales.
