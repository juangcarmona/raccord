## Rule

A saved match between an outside equipment reference (an import row value) and an own item is proposed automatically the next time the same reference appears.

## Rationale

Avoids repeated manual matching.

## Examples

See SB-PRJ-SAVED-MATCH-SUGGESTED.

## Exceptions

None.
