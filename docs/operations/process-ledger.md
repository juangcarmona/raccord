# Process ledger

- 2026-11-15: After applying a Product Change, keep its `change.md` decision record and remove the archived `proposed/` copies in the same reviewed change. Check links to those copies, then run ProductShape validation and OpenSpec citation verification. The accepted model remains in `docs/product/model/`; Git history retains earlier artifact versions.
- 2026-11-15: Before releasing an epic queue, compare the root package, workflow source pins and runtime receipts, then qualify evidence preparation against the real accepted model. Record owner product approval once and carry it into each issue, preserve a revision-bound inventory, and hold dependent work with `future` when a shared technical prerequisite fails. Workflow installation and compiled locks are not proof of an advancing unattended controller; verify a validated native result and the first PR before reporting the train as operating.
