## Rule

A function whose include-in-price flag is off contributes nothing to the project price, while it still counts for planning and costs.

## Rationale

Some roles are internal or included elsewhere.

## Examples

A project manager function excluded from price still appears on the call sheet.

## Exceptions

None.
