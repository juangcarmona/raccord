## Definition

The period during which a resource planned on a function is occupied. It is defined on the function (or its group) and can be overridden per crew assignment, for example to make one technician arrive earlier. It drives availability, wages and planned cost, but not the customer price.

## Distinguish From

Function usage period: what the customer pays for. Equipment planning period: equipment out of stock.

## Usage

Crew calls, availability, cost.
