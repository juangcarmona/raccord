## Definition

A configured connection between the company's installation and an external system that exchanges data with it: the public interface and its token, tax-authority reporting, calendar feeds and the company registry lookup. Each integration has a kind and kind-specific settings. Integrations are managed in one place of the configuration by users with configuration access.

## Distinguish From

Not an import (a one-off file read by the user) and not a document export (a file the user downloads). An integration persists and acts repeatedly.

## Usage

Listed and configured in the workspace configuration; its failures are shown to users with configuration access.
