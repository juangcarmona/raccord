## Definition

The behavioural kind of a project, fixed by its project type: regular project (customer, rental and/or crew and/or consumables) and without-times sale project (no mandatory period).

## Distinguish From

Project type: user-defined label carrying defaults; several types can share a category.

## Usage

Determines whether a time schedule is mandatory and how stock is affected.
