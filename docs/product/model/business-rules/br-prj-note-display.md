## Rule

A note is shown in each place selected as its display target (details panel, warehouse handling, crew personal schedule, quotations and contracts, invoices, other documents) and nowhere else.

## Rationale

Different audiences need different notes.

## Examples

See SB-PRJ-NOTE-ON-PACKING-SLIP-ONLY.

## Exceptions

None.
