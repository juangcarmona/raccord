# Manual warehouse booking

Expose the already accepted manual packing workflow in the authenticated project workspace. Operators can see project equipment lines, prepare them, book them out without a scan code, and record their return. The server remains the authority for transition order, stock movement and tenant isolation.

This change does not alter the canonical product model or add new warehouse semantics; it makes the existing manual booking use case reachable from the web UI and adds browser evidence.
