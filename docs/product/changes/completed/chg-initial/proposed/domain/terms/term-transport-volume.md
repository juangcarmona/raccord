## Definition

The space an item occupies in transport. It can be derived automatically from the item's length, height and width (in centimetres). Combined with the packed-per quantity it determines how much volume a planned quantity needs. Physical kits use their own dimensions; virtual kits use their content; accessories count individually.

## Distinguish From

- Packed-per quantity: the number of pieces sharing one transport package.

## Usage

Feeds project volume totals for transport planning.
