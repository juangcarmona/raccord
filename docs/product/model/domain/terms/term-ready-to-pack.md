## Definition

A flag on a project by which the planner hands it over to the warehouse. Lifecycle: Not ready (initial state, also for all existing projects) to Ready (set by the planner, or automatically when someone books equipment of it). Ready can be switched back to Not ready only while nothing of the project has been booked; after the first booking it is locked.

## Distinguish From

Not a warehouse status and not a project status.

## Usage

Controls which packing lists the warehouse sees.
