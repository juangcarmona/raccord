## Definition

Example records placed in a newly set up installation so every function can be tried immediately: projects, equipment and folders, contacts, vehicles, documents, templates, tasks and similar.

## Distinguish From

Not the company's own data; not the default settings and roles, which remain when sample data is removed.

## Usage

Exploring the product before setting it up.
