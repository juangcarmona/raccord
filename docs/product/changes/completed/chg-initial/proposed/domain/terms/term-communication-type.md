## Definition

The category of an outgoing communication: tasks and appointments assigned to crew; planning and invitations sent to crew; quotations, contracts, invoices and other documents sent to contacts.

## Distinguish From

Document type: the template classification; the communication type classifies the message.

## Usage

Used to filter the communication log.
