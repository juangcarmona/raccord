## Definition

When a task is due. Three forms: none (the task stays active indefinitely), a fixed date (the task is flagged overdue once the date passes uncompleted), or a relative deadline expressed as a number of days before or after a moment of the project schedule (for example three days before load-in), which moves when project times change.

## Distinguish From

Time period: has start and end and books people or equipment.

## Usage

Overdue flags, templates, notifications.
