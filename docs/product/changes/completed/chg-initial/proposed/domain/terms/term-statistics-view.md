## Definition

A saved analysis with name, description, statistic type (projects, equipment, invoices, crew members, vehicles), chosen columns, time period and filters, optionally shown as a pie or bar chart. Figures are recalculated from current data every time.

## Distinguish From

Project financial overview (one project); data export (raw records).

## Usage

Used to compare revenue, margins, payment behaviour, utilisation and costs over many records.
