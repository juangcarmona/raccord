## Definition

A bookkeeping account with name and code to which revenue and costs are booked. Seven defaults exist (rental, sale, crew, transport, insurance, other, default); items, functions and additional costs receive a default ledger by kind, changeable per item and per project.

## Distinguish From

Revenue category.

## Usage

Invoices are exported as ledger rows.
