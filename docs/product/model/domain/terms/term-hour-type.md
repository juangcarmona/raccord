## Definition

Classification of registered time with configurable behaviour. Default types: worked, correction (obsolete) and compensation; further types can be added. Attributes: name, colour, payroll code and whether it requires approval. Each type also defines how it affects the worked-hours total.

## Distinguish From

Crew document type: classifies documents, not time.

## Usage

Routing time to approval or direct registration, payroll export.
