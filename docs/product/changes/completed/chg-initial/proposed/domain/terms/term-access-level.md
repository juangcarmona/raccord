## Definition

The graded value of a record-access permission. Levels are cumulative: no access < view only < view and edit < view, edit and delete; some permissions add a further step (approve for other people's hours; adjust invoice references for activities). Ownership-scoped permissions combine a level with a scope (own records or all records).

## Distinguish From

Not module visibility, which is a yes/no gate preceding any level.

## Usage

Expresses most permissions of a role.
