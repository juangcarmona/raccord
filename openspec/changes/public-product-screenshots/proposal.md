## Why

Visitors need to see what the current application looks like, but Raccord does not offer a hosted demo. Successful E2E journeys already exercise real product screens with synthetic data and can provide safe, reproducible screenshots.

## What Changes

- Select screenshots from successful browser journeys that use synthetic fixtures.
- Publish a small set of current product screens with useful alt text and captions.
- Copy the selected images into the static-site output and test their presence and links.
- Record the browser test, capture point, source artifact and refresh procedure for every published image.

## Capabilities

### Modified Capabilities

- `public-capability-overview`: visitors can inspect verified product screens without receiving a public application instance.

## Product definition impact

The images illustrate existing invoice and project workflows; they add no product behavior and contain no real customer data.
