## Definition

All equipment of every packing list of the project has been returned. Set automatically by the last return, or by a user.

## Distinguish From

Complete: the team has closed the project; execution done can still have open follow-up work.

## Usage

Confirmed group; signals the project is ready for closing and final invoicing.
