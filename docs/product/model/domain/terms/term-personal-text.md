## Definition

Free text, optionally with images, written for one generated document and printed in it, for example an introduction on a quotation. It can be typed or started from a text template.

## Distinguish From

E-mail message text: accompanies a document in an e-mail; the personal text is part of the document itself.

## Usage

Entered when generating a document.
