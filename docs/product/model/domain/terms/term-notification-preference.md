## Definition

The channels through which a person receives planning and invitation notifications (email, mobile web app notification, in-product web notification), plus opt-outs such as job board alerts and time registration change alerts. Only the person can change it; planners can only see it.

## Distinguish From

Invitation template settings: content, not channels.

## Usage

Ensuring schedules reach people.
