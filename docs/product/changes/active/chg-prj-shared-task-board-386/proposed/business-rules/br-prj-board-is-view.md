## Rule

A task board shows the tasks matching its scope; a task can appear on several boards at once and has a single status shared by all of them.

## Rationale

Avoids duplicate tasks.

## Examples

See SB-PRJ-TASK-ON-TWO-BOARDS.

## Exceptions

None.
