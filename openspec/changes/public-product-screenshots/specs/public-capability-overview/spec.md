## ADDED Requirements

### Requirement: Public screenshots come from verified synthetic workflows

The public site SHALL display only screenshots captured from successful browser journeys using synthetic data, with alt text and captions that accurately describe the visible current workflow.

#### Scenario: Visitor inspects the invoice workflow

- **WHEN** a visitor views a published product screenshot
- **THEN** it shows a workflow verified against the application and contains no real customer data, secrets, test traces or failure state
