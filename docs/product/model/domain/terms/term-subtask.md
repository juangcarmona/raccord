## Definition

A checklist item inside a task with only a title and a done/not-done state. It cannot be assigned, has no deadline, no planned time and no tracked time.

## Distinguish From

Task: has owner, deadline and hours.

## Usage

Breaking one person's work into steps; imported as repeated rows of the parent task.
