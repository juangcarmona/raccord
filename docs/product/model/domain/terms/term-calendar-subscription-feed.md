## Definition

A read-only address in the common calendar-exchange format that calendar applications import to display a stream. Changes flow only from the product to the application, and the application decides how often it refreshes (some refresh once a day).

## Distinguish From

Not a two-way synchronisation: items created in the application never reach the product.

## Usage

Used to show the schedule in any calendar application.
