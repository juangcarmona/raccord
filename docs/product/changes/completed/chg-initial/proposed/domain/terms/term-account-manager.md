## Definition

The Admin or Office user responsible for a project. Notes are by default visible only to account managers; account managers receive e-mail notifications about incoming project requests; presets such as 'my pending projects' filter on it.

## Distinguish From

Contact person: someone at the customer. Assignee: the person responsible for a task.

## Usage

Project ownership, follow-up, note confidentiality.
