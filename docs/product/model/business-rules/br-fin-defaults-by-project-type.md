## Rule

The project type determines the default document template, letterhead and additional conditions of a project's financial documents; the user may pick others per document or project.

## Rationale

Different kinds of jobs need different documents and conditions.

## Examples

A dry-hire project type defaults to the rental template and rental conditions.

## Exceptions

None.
