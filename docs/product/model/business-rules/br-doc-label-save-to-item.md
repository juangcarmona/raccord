## Rule

After generating equipment labels, the user may save the generated document to the article it was made for, where it stays available.

## Rationale

Labels can be reprinted without regenerating.

## Examples

See SB-DOC-LABEL-SAVED-TO-ITEM.

## Exceptions

None.
