## Definition

A check-in mode that books returning equipment back without opening each project: the technician scans and, for each article, chooses the project and the quantity. Each scanned row shows article, project and an optional note.

## Distinguish From

Not a per-project check-in.

## Usage

Unloading trucks that carry several jobs.
