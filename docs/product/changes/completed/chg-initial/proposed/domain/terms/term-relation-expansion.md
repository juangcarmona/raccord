## Definition

A request option that replaces the reference of a related record by the full related record inline in the response, for one or more named relations (linked items, siblings, children and custom fields that point to records).

## Distinguish From

Not field selection; expansion adds related data rather than choosing fields.

## Usage

Reduces the number of calls an integration needs.
