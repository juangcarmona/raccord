## Definition

A node of a user-defined hierarchical folder structure in which records of one module are stored: contacts, equipment, crew members, vehicles each have their own separate structure. Each record lives in exactly one folder. Folders can be added as root folders or subfolders, renamed, reordered and moved; a folder that still contains records cannot be deleted. Imports place records by a folder path and create missing folders under a chosen root.

## Distinguish From

Tag: grouping across folders; folders are for storage, not grouping. File folder: inside one record.

## Usage

Organising the contact database (for example freelancers/audio technicians).
