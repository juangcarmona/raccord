## Definition

The new moment at which delayed equipment is expected back, recorded when marking equipment groups delayed. It becomes the end of their planning period; it can be set again repeatedly.

## Distinguish From

Not the usage period end: what is charged does not move.

## Usage

Recorded during check-in handling.
