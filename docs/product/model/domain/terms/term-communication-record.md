## Definition

One logged outgoing communication from the product. Attributes: recipient (crew member, contact or contact person), communication type (TERM-COMMUNICATION-TYPE), channel (TERM-COMMUNICATION-CHANNEL), subject, message content, sending user, date and time sent and, for e-mails, delivery status.

## Distinguish From

Project note: internal information; a communication record documents what was sent to someone. Audit event (TERM-AUDIT-EVENT): records changes to data.

## Usage

Listed in the communication log and on the recipient's record.
