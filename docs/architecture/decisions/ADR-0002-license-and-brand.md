# ADR-0002: AGPLv3 code with a separate brand boundary

- Status: accepted
- Date: 2026-10-06

## Decision

Code and documentation are licensed under AGPLv3. Raccord's name, logo, and official product identity are not granted as a trademark license by the code license.

## Rationale

This supports self-hosting and community contributions while keeping hosted modifications available under the reciprocal license and distinguishing official releases from forks.
