## Rule

A one-off function exists only in the project where it was created and cannot be added to other projects unless converted into a default function.

## Rationale

Keeps the default catalogue clean.

## Examples

A one-off pyrotechnician function becomes reusable only after conversion.

## Exceptions

None.
