## Definition

A set of per-topic signals (for example equipment, crew and transport, financial follow-up) that show for each project whether work is not applicable or not yet started, complete, needed in the future, or urgently needed. Each signal explains the required action on request.

## Distinguish From

Project status: the overall lifecycle stage.

## Usage

Shown inside a project and as an overview column.
