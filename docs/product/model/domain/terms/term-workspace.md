## Definition

The company's own installation in which it runs its operations: projects, equipment, contacts, crew, documents, settings and users all belong to the one company the installation serves. Attributes: company details, workspace language, default time zone, settings, roles and users. A person reaches it through a user account that an administrator created for them as a crew member.

## Distinguish From

Not the personal profile, which belongs to the person. Not a legal entity beyond the one company the installation serves.

## Usage

Set up once when the company starts using the product.
