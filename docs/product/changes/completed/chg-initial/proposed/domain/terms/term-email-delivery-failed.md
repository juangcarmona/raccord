## Definition

An outgoing e-mail that the company's mail account or the recipient's server refused (a bounce), for example because the recipient address does not exist, the recipient server rejects the sender, or the mail account refused or limited the sending. The refusal reason is available on the message.

## Distinguish From

Spam filing: the message was accepted and is therefore sent, even if it ends in a spam folder.

## Usage

Prompts the user to correct the address, contact the recipient or check the mail account setup.
