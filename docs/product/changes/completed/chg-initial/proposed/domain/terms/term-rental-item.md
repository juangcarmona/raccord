## Definition

An equipment item with rental usage. It carries a rental price per day, and a list price used for valuation. Planned rental quantities are deducted from availability for the project period and return to stock afterwards.

## Distinguish From

- Sale item: consumed, priced with a sale price.

## Usage

The common case for audiovisual equipment.
