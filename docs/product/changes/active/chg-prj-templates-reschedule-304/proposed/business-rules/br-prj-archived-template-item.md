## Rule

When a project copies a planned item that no longer exists in the active catalogue (for example archived), the line is kept but presented as struck out.

## Rationale

The user must notice and replace it.

## Examples

A template still lists a retired speaker; new projects show it struck out.

## Exceptions

Fix by building a new template without the item.
