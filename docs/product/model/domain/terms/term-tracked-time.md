## Definition

Hours registered against a task, either entered as a duration afterwards (several entries per task allowed) or captured by a timer started and stopped by the person (one running timer per person across the web and the mobile web app). Tracked time can optionally be turned into a time registration, follows the same approval process (pending until approved, read-only once approved), and rolls up into the linked service. Tracked time on tasks without a project is kept for reporting but not in any project financials.

## Distinguish From

Planned time: the estimate. Hours on functions and shifts: crew time registration.

## Usage

Comparing estimate and actual, service actual cost, exports.
