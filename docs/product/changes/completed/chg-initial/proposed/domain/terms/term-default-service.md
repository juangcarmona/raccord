## Definition

A reusable service definition (name, estimated time, price, cost per hour, VAT class, ledgers, details and optional tasks) that can be added to any project. Adding it to a project copies it into a project service group and creates its tasks; the project copy can then be adjusted without changing the default.

## Distinguish From

Project service: the copy inside one project.

## Usage

Standard packages sold repeatedly.
