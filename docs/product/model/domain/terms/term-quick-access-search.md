## Definition

A keyboard-invoked search across recently opened records, projects, equipment, contacts, invoices, crew members, tasks and vehicles, opening the chosen record directly.

## Distinguish From

Not module filters or saved views.

## Usage

Fast navigation, for example from a project number a colleague mentions.
