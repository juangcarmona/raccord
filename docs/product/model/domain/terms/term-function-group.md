## Definition

A named set of functions within a project with its own usage and planning period. A group can be linked to time-schedule periods (its functions then follow the schedule), have its own times, or carry only a duration. Groups can be created from selected time-schedule periods. Functions outside a named group belong to an implicit ungrouped set. Groups organise work by part of the day, stage or topic and filter planning views.

## Distinguish From

Shift: non-project work. Time period: an entry of the time schedule, which a group may be linked to.

## Usage

Organising functions, retiming many functions at once, changing the charged period.
