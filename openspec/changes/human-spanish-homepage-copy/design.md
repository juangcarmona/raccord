## Copy approach

Name the work visitors can do: register a customer, create a project, record billable work, prepare an invoice, issue it and retrieve its PDF and audit history. Use the same plain wording in navigation, headings and links. Preserve the sign-in, no-demo, no-public-registration and no-compliance-claim statements.

## Accessibility

The GitHub icon is decorative and has an accessible visible link name. All navigation links describe their destination. Existing responsive and keyboard-navigation checks remain in the browser journey.
