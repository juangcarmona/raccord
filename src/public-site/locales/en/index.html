Projects and invoicing

What is Raccord?

Projects bring together work that needs to be reviewed and billed. Raccord links customers, projects, billable work and invoices so you can follow that work in one system.

You can read the code and check what the project includes today. Raccord is still in development; review its limits before using it in your business.

  3. 03Issue and file

    Issue the invoice, download its PDF and review its audit history.

What is not available yet

Sign-in is required. There is no hosted demo or public registration. The interface does not yet support payment management or sending invoices to VERI*FACTU. Raccord does not claim legal or tax compliance.
