## Definition

The content of a kit as it stands on one project. As soon as a kit with default content is planned, its default content becomes that project's planned content, whether or not anyone edits it. Edits (where allowed) change only that project and never the catalog default content. The warehouse crew sees planned content when packing.

## Distinguish From

- Default content: catalog definition.

## Usage

Used by the warehouse to pack exactly what the account manager or planner decided.
