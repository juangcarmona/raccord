## Rule

A request can be declined at any point before a project is created from it; the staff member who created it is informed by e-mail.

## Rationale

The person who raised a request needs to know it will not be handled.

## Examples

See SB-PRJ-DECLINE-NOTIFIES-REQUESTER.

## Exceptions

None.
