## Definition

A shortage kind in which part of the planned quantity is not reserved although enough own stock is free. It is resolved without external action, by reserving manually or by saving the project again so the automatic reservation runs.

## Distinguish From

Not a stock shortage: no extra equipment is needed.

## Usage

Explained on the project plan; typical after a competing project is cancelled.
