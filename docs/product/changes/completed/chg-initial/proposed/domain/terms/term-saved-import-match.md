## Definition

A remembered correspondence between a value used by an outside source (a row of an imported equipment list) and an item of the company's own catalogue, so the same value is matched automatically next time.

## Distinguish From

Catalogue item code: the company's own identifier.

## Usage

Equipment list imports.
