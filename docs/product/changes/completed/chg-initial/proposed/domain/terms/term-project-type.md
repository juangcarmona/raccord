## Definition

A configurable classification chosen for every project that preloads defaults and distinguishes projects in overviews and statistics. Attributes: name (for example dry hire, sale, festival), category, colour, default project document template, call sheet template, packing slip template, quotation, contract and invoice templates (each optionally 'remember last used'), default letterhead, default number series for quotations, contracts, invoices and credit notes, default invoice moment, and default additional conditions.

## Distinguish From

Project category: the behavioural kind (regular, sale). Project template: copies content, not settings.

## Usage

Chosen at project creation; filters and statistics by type; colour in calendar and timeline overviews.
