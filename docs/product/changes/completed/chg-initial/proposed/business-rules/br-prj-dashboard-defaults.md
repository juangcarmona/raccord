## Rule

A dashboard starts with the invitations, time registration, personal schedule and tasks widgets; seeing, editing or adding widgets requires the dashboard permission of the user's role.

## Rationale

Useful start, controlled access.

## Examples

A new user sees four widgets.

## Exceptions

None.
