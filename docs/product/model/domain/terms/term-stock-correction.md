## Definition

A stock movement that sets the current stock of an item or sale item to a stated new level, recording the difference, with an optional name and description explaining why (for example an incomplete delivery).

## Distinguish From

- Delivery or reduction: adds or removes a quantity rather than stating the new total.
- Count adjustment: correction produced by completing an inventory count.

## Usage

Fixes inaccurate stock records.
