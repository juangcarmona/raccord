## Intended Outcome

All document types the company uses carry its stationery, logo and colours, and are proposed automatically per project type.

## Entry Conditions

The built-in templates exist for the document types.

## Journey Narrative

The administrator uploads the letterhead, sets the language, country, subject and file name of the templates in use, adds the logo and colours, and finally sets the default letterhead per project type.

## Variants and Branches

Documents in another language only need their language and country set (UC-DOC-PREPARE-FOREIGN-LANGUAGE-TEMPLATE).

## Completion Conditions

Generating a quotation for a new project proposes the branded template and letterhead.
