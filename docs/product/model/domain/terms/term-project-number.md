## Definition

An identifier of a project, unique within the installation. Left empty, it is assigned automatically as the next value of the project number series (whose starting value is configurable); a custom value may be entered instead. It is a reliable key to match tasks to projects during imports.

## Distinguish From

External reference: the customer's identifier, such as an order number.

## Usage

Overviews, documents, imports.
