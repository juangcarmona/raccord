## Definition

A file uploaded to, or a generated document saved to, a record such as a project, contact or contact person, equipment item, task, crew member, vehicle or lost-equipment report. Attributes: name, content, folder, confidentiality inherited from its folder. Uploaded files and generated documents are stored on the installation's own storage.

## Distinguish From

Generated project document: a file produced from a template; once saved to the project it is an attached file that cannot be moved between folders.

## Usage

Maps, riders, scenarios, drawings, briefings for crew.
