# Raccord design system

Status: exploratory v1  
Last updated: 2026-10-06

Raccord should feel like a calm, precise control surface for audiovisual production operations: clear at a glance, robust under pressure, and distinctive without relying on film clichés.

- [Visual direction](visual-direction.md)

## Design north star

**Continuity made visible.** The interface should help a production team keep people, equipment, projects, documents, and invoices aligned from first request to final delivery.

## Current status

The mark and palette are exploratory. Before a public launch, create a final vector set, verify trademark availability, test contrast, and validate the identity with audiovisual users.
