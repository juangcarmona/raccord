## Definition

A mark on a project stating it was billed outside the product (other software, an accountant or certified invoicing software required by a public body), which removes it from the invoicing queue without creating an invoice.

## Distinguish From

Issued invoice; exported invoice.

## Usage

Set from the invoicing queue.
