## Rule

A project template cannot be edited directly; to change it, a project is created from it, adjusted, saved as a new template, and the old template deleted.

## Rationale

Templates are snapshots of projects.

## Examples

Adding a lighting group to a template requires a new template.

## Exceptions

None.
