## Definition

The common project category for an event or rental for a customer: equipment only (dry hire), crew only, or both, optionally with consumables and sale items. It has a customer, a location, a mandatory time schedule, and may have additional costs, project costs, financials, crew and transport planning and a change history.

## Distinguish From

Sale project: no mandatory period.

## Usage

Default category for new projects.
