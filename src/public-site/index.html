Qué es Raccord

Un rodaje conecta planificación, equipo, trabajo realizado y administración. Raccord está construyendo una herramienta para que las productoras y empresas de alquiler puedan seguir ese trabajo desde el proyecto hasta la facturación.

El código y las instrucciones para ejecutar el proyecto están disponibles para que cada equipo pueda revisar cómo funciona y decidir si encaja en su forma de trabajar.

Estado del proyecto

Una primera parte ya se puede probar

El primer flujo implementado enlaza proyectos, trabajo facturable y emisión de facturas. El proyecto sigue en una etapa temprana y continúa creciendo.

  1. 01Organizar

    Crear un proyecto y registrar trabajo facturable.

  2. 02Preparar

    Crear un borrador y validar sus datos antes de emitirlo.

  3. 03Emitir

    Conservar la factura emitida, su PDF y el registro de auditoría.

Lo que todavía no está listo

La autenticación aún no está implementada: no expongas una instalación de Raccord en Internet. Los pagos, las facturas rectificativas y el envío VERI*FACTU tampoco están implementados. Raccord no afirma cumplir requisitos legales o fiscales.
