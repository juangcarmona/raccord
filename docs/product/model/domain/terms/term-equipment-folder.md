## Definition

A node in the hierarchical folder tree that organises the equipment catalog (for example audio / microphones / wireless). Each item sits in exactly one folder. Imports place items under a chosen root folder, following the folder path given per row; rows without a path land directly in the root folder.

## Distinguish From

- Tag: a free label; an item may carry many tags but sits in one folder.
- Equipment group: organises a project's equipment list, not the catalog.

## Usage

Used to browse and filter the catalog and to structure imports.
