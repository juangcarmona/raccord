## Rule

The information shown in invitations (due date, location, client name, function group, project leader, account manager) follows the invitation template defaults and can be changed for each send.

## Rationale

Some companies withhold location or client until acceptance.

## Examples

Client name hidden by default but shown for a regular crew member's invitation.

## Exceptions

None.
