## Definition

Lifecycle of a crew rate: active (selectable) and archived (no longer selectable, kept for history and listed separately). Transition active -> archived only when no future function or shift and no crew member still uses it. Past functions still using an archived rate show it struck through.

## Distinguish From

Deletion: not the preferred path, because history would be lost.

## Usage

Retiring outdated tariffs, for example at year change.
