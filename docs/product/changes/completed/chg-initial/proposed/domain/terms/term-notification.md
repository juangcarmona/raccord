## Definition

A message the product sends a user about an event relevant to them, through each channel they enabled for its category: email, mobile web app notification or in-product web notification (listed under the notification bell).

## Distinguish From

Not an email the user sends to customers or crew; not a task.

## Usage

Keeps users informed without checking every module.
