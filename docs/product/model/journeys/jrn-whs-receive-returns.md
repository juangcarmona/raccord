## Intended Outcome

All equipment is back, loss recorded, consumption counted.

## Entry Conditions

Return lists are due or delayed.

## Journey Narrative

Gear is scanned back (several jobs at once), losses reduce stock with optional charges, unused consumables are counted back.

## Variants and Branches

Late gear is marked delayed with an expected date; early returns release stock; found items restore stock later.

## Completion Conditions

All lists returned; project finalizing.
