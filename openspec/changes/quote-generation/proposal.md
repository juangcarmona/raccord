# Quote generation

Add the first commercial document workflow: an operations coordinator can generate a numbered, immutable quote snapshot from a project's priced plan. The snapshot retains project and customer identity, copied lines, payment terms and an expiry derived from financial settings.

PDF rendering, templates, customer review, signing and delivery remain separate slices.
