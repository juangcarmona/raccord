## Rule

When a document is signed digitally, the signed copy is stored in the project's files.

## Rationale

The signed version is the proof of agreement.

## Examples

See SB-DOC-QUOTE-SIGNED-CONFIRMS-PROJECT.

## Exceptions

None.
